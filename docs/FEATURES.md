# الميزات والقدرات — V0.1

## ما يفعله النظام فعلاً

### 1. الهوية المُثبَّتة
- توليد مفتاح Ed25519 مرة واحدة.
- توقيع أي رسالة بمفتاح المالك.
- التحقق من أي توقيع.
- المفتاح الخاص محمي بصلاحيات 600.
- لا توليد مفتاح جديد بعد Genesis.

### 2. السجل غير القابل للتعديل
- كل سجل مرتبط بالسجل السابق (hash chain).
- أي تعديل حرف واحد يُكشف فوراً.
- سجل Genesis تلقائي عند أول فتح.
- Checkpoints موقّعة كل 50 سجلاً.
- full_verify يعيد تفاصيل دقيقة.

### 3. السياسات الموقّعة
- الافتراضي: deny.
- الأدوار مع trust_min + permissions.
- السياسة تُوقَّع عند أول تحميل.
- أي تعديل يدوي → رفض.
- fnmatch للصلاحيات (يدعم *).

### 4. البوابة الإلزامية
- كل طلب يُقيَّم مقابل السياسة.
- قرار allow/deny يُسجَّل تلقائياً.
- الرفض له سبب واضح.
- reload_policy متاح.

### 5. الإيقاف الفوري
- تفعيل عبر ملف kill.flag.
- كل العمليات تتوقف عند التفعيل.
- رفع الإيقاف يتطلب توقيع المالك.
- التوقيع الخاطئ لا يرفع الإيقاف.
- كل تفعيل/رفع يُسجَّل.

### 6. حاكم الموارد
- حدود لكل فرع، لكل مورد.
- النافذة: 60 ثانية.
- التجاوز يُرفض فوراً.
- كل تجاوز يُسجَّل.
- reset() لإعادة الحالة.

### 7. سجل الفروع
- لا فرع يعمل دون تسجيل.
- التسجيل يتطلب توقيع المالك.
- الرسالة المُوقّعة: commitment(name, kind, permissions).
- كل فرع له branch_id فريد (br_xxxxxxxxxxxx).
- كل تسجيل يُسجَّل.

### 8. نقطة الدخول الموحدة
- كل فعل يمر عبر execute().
- Kill Switch → Permission Gate → Resource Governor → Audit.
- لا يمكن تجاوز أي طبقة.
- كل استدعاء ناجح يُسجَّل.

## ما لا يفعله النظام (متعمداً)

- لا وكلاء AI — V0.3
- لا ذاكرة حية — V0.2
- لا نماذج محلية — V0.3
- لا إنبات تلقائي — V0.4
- لا تطور ذاتي — V0.4+
- لا وصول شبكي — V0.3
- لا واجهة ويب — V0.5
- لا جدولة تلقائية — V0.2

هذا تصميم، ليس نقصاً.
V0.1 يُثبت أن الحكم يعمل قبل وجود ما يُحكم عليه.

## القدرات التقنية

يعمل على الهاتف فقط:
- Python 3.13 على Termux كافٍ.
- لا GPU، لا RAM كبيرة، لا خادم.
- كل الملفات نصية (JSONL, YAML, Python).
- لا اتصال إنترنت مطلوب.

الأداء المُقاس:
- sign: < 1ms
- verify: < 2ms
- append: < 5ms
- full_verify على 1000 سجل: < 1s
- permission_gate.check: < 10ms

التخزين:
- سجل واحد: ~ 400 bytes
- 10,000 سجل: ~ 4 MB
- مفتاح خاص: 120 bytes
- سياسة: 600 bytes
- الكود كاملاً: ~ 50 KB

كل شيء يعمل في أقل من 100 MB.

## الميزات الأمنية

الموثقة والمُختبرة:
- Tamper Detection
- Policy Integrity
- Authorization Mediation
- Resource Isolation
- Emergency Stop
- Owner Signature
- Branch Registration
- Append-Only Audit

غير المُختبرة في V0.1:
- Persistence after reboot
- Concurrent writes
- Log rotation
- Distributed trust

## ما يميّز هذا المشروع

1. البنية لا تعتمد على نموذج AI معين.
2. الحكم قبل المحكوم.
3. الميثاق قبل الكود.
4. التوثيق مع البناء.
5. يعمل بالكامل على هاتف.
6. المفاتيح لا تفارق الجهاز.
7. الاستعارة مُترجَمة هندسياً، لا شعارات.
