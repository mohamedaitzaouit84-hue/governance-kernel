# بوابات التحقق — Gates

> كل إصدار يجب أن يجتاز هذه البوابات قبل أن يُعتبر مُنجزاً.
> مصدر الإلهام: QSRB-v0.4 Audit Protocol.

## المبدأ الأساسي
"الفصل الإحصائي ليس تحديداً سببياً."

## البوابات العشر

### Gate 0 — تجميد الإصدار
تثبيت الكود والمعاملات والـ seeds قبل أي تجربة.

### Gate 0X — سلامة الضوابط
كل ضابط مستقل، ليس نسخة من النظام.

### Gate A — التدقيق الجنائي
كشف aliasing: هل كل عنصر فريد فعلاً؟

### Gate B — عزل العشوائية
كل فرع له random stream و seed خاص.

### Gate C — تكافؤ الموارد
كل مقارنة على موارد متكافئة (±5%).

### Gate D — الشبكة البنيوية
اختبار النظام عبر نطاق كامل من المعاملات.

### Gate E — شكل الدالة
فهم كيف يتغير النظام، لا فقط أنه يتغير.

### Gate F — الزوجية الإحصائية
مقارنة النظام والضابط على نفس البذرة.

### Gate G — الاختبارات المتعددة
اختبار أولي واحد محدد مسبقاً. منع p-hacking.

### Gate H — الاجتثاث السببي
حذف كل مكوّن لاختبار سببيته.
